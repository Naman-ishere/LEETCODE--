## 📝 Solution Format

Each solution will generally contain:

1. The problem name and number
2. A link to the original LeetCode problem
3. The approach used
4. Time complexity
5. Space complexity
6. The final implementation

Example:

```text
Problem: Two Sum
Difficulty: Easy
Language: C++

Approach:
...

Time Complexity: O(n)
Space Complexity: O(n)
```
